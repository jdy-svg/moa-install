# moa 설치

휴대폰 안에서만 동작하는 사진 정리 앱입니다. 사진은 휴대폰 밖으로 나가지 않습니다.

## 설치 방법 (안드로이드)

1. [최신 설치 파일 받기](../../releases/latest) 에서 `moa-x.y.z.apk`를 누릅니다.
2. "이 파일은 바이러스 검사를 할 수 없습니다" 안내가 나오면 그래도 내려받습니다.
   스토어 밖의 앱에 구글이 항상 띄우는 안내입니다.
3. 받은 파일을 누릅니다. "출처를 알 수 없는 앱" 안내가 나오면 허용합니다.
4. "안전하지 않을 수 있습니다" 경고에서 **무시하고 설치**를 누릅니다.
5. 앱을 열고 사진과 위치 권한을 허용합니다.

## 처음 쓸 때

- 사진을 살펴보는 데 시간이 걸립니다. 6천 장 기준 2~3시간이고, 충전하면서 켜 두면 알아서 진행합니다.
- 아이 사진을 모으려면 **아이** 화면에서 아이를 등록하고 얼굴을 골라 주세요.

## 필요한 것

- 안드로이드 10 이상
- 64비트(arm64) 휴대폰. 요즘 나온 기기는 모두 해당합니다.
